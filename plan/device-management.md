# 设备管理剩余实施计划

## 1. 范围

本计划仅保留尚未完成的设备管理工作：

1. 批量移动设备分组。
2. 批量电源操作。
3. 服务端对高风险写操作的权限校验、审计、输入校验和限流。
4. 设备管理页面、控制客户端和端到端测试补齐。

不在本计划范围内：远程终端、远程桌面、完整文件管理、用户角色管理、审计日志页面、批量命令、邮件邀请和邀请链接。

## 2. 已完成基础

以下能力已实现，不再作为待办：

- 设备列表默认展示全部分组，支持 URL 分组筛选、本地分页、页大小切换和跨页选择提示。
- Mesh Agent 安装引导支持下载包、安装脚本、二维码和移动端配对信息。
- 可编辑设备名称、描述、标签和所属分组；可删除设备并显示确认信息与失败反馈。
- 设备分组支持新建、编辑、删除、分页，并能跳转到已按分组筛选的设备列表。
- `refreshSnapshot()` 可重新拉取设备与分组快照，并在写操作后作为刷新兜底。
- 控制客户端已具备批量移动分组和批量电源的基础接口。

## 3. 安全前置条件

设备删除、移动分组和电源操作均属于写操作。业务网关必须负责身份认证、设备/分组范围授权、输入校验、频率限制和审计记录；前端的隐藏或禁用状态不得被视为安全控制。

生产环境开放高风险操作前，应完成短期访问令牌、可撤销刷新会话和安全 Cookie 或等效机制，避免浏览器保存可还原的长期凭据。

需与业务网关确认：

| 操作 | 网关职责 | 最小返回信息 |
| --- | --- | --- |
| 移动分组 | 源/目标分组权限、成员变更审计 | 每台设备的成功/失败结果 |
| 电源操作 | 操作权限、设备状态校验、审计、限流 | 已受理或逐设备结果 |

还需明确批量电源操作的 `actiontype` 与目标 MeshCentral 版本之间的实际映射，以及成功写入后网关是否保证推送设备/分组变更事件。

## 4. 阶段 1：批量移动分组与批量电源 UI

### 批量操作栏

当表格至少选中一台设备时，显示紧邻表格的批量操作栏：

- 已选设备数与“清空选择”。
- 移动分组。
- 电源操作。
- 现有批量文件上传入口。

每次提交前，必须基于当前 store 快照重新解析所选设备，排除已经删除、无权限或不符合操作条件的目标。

### 批量移动分组

- 选择目标分组并展示实际目标数。
- 分类提示无权操作、设备不存在、已属于目标组的设备。
- 调用 `updateManyGroup()` 后展示逐设备结果。
- 成功项从选择中移除，失败项保留以支持重试。

### 批量电源

- 支持唤醒、重启、休眠和关机。
- 重启、休眠和关机必须二次确认；确认内容展示目标总数、在线数和离线数。
- 默认跳过离线设备；仅在服务端明确支持时才允许用户选择离线排队。
- 明确区分“请求已受理”和“设备操作已确认”。
- 调用 `powerMany()` 后展示逐设备结果，不能将已提交误显示为设备端执行成功。

### 完成标准

- 批量操作具有加载和防重复提交状态。
- 支持部分成功、失败、跳过和可读失败原因。
- 高风险电源操作具备确认文案和服务端审计依赖说明。
- 操作完成后刷新设备与分组快照；刷新失败时保留缓存并提示数据可能过期。

## 5. 阶段 2：控制客户端与结果模型完善

完善 `BatchOperationResult` 和 `BatchDeviceResult`，使 UI 能展示：

```ts
interface BatchDeviceResult {
  deviceId: string;
  deviceName: string;
  status: 'queued' | 'running' | 'submitted' | 'succeeded' | 'failed' | 'skipped';
  message?: string;
  startedAt?: number;
  finishedAt?: number;
}
```

控制客户端测试需覆盖：

- 批量移动分组的空参数、部分失败与受限并发。
- 批量唤醒请求与其他电源操作的单设备降级路径。
- 无效电源动作、网关拒绝、超时和连接中断。
- 返回状态仅表示已提交或已受理时的 UI 语义。

## 6. 阶段 3：测试与验收

### 前端测试

新增设备管理页面级测试，覆盖：

- 默认全部分组、URL 分组筛选与组合筛选。
- 本地分页、跨页选择和清空选择。
- 编辑、删除确认和 Mesh Agent 安装引导。
- 批量移动、电源操作的部分成功、离线跳过、超时和断线状态。
- 从分组页跳转至设备页。
- 实时事件和显式刷新导致的状态更新。

### 端到端测试

在具备业务网关测试环境后，覆盖：

- 不同角色对查看、编辑、删除、移动分组和电源操作的授权。
- 安装包、脚本和移动端配对信息可用，且安装后设备出现。
- 网关断线、重连和快照恢复。
- 设备删除、移动分组和电源操作的审计记录。

### 质量门禁

每个阶段完成后执行：

- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- `pnpm build`
- `pnpm format:check`

## 7. 推荐实施顺序

1. 确认业务网关的授权、审计和批量电源协议契约。
2. 完善批量结果模型与控制客户端测试。
3. 实现批量移动分组 UI。
4. 实现批量电源 UI 与危险操作确认。
5. 增加页面测试、端到端测试和质量门禁验证。
6. 完成生产认证会话改造后，开放高危写操作。
