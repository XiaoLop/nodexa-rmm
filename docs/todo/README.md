## P0：上线前必须完成

### 1. 认证与会话安全 (最后修改)

- [ ] 改为通过业务网关认证接口登录，由服务端签发短期访问令牌。
- [ ] 使用安全 Cookie 或等效机制维护刷新会话。
- [ ] 禁止在 `localStorage` 或 `sessionStorage` 中保存可还原的用户名、密码组合。
- [ ] 实现访问令牌刷新、会话过期提示和自动退出。
- [ ] 区分认证失败、网络失败、网关不可用和权限不足等错误。
- [ ] 增加登录限流、连续失败提示和必要的安全审计事件。
- [ ] 退出登录时清理客户端连接、缓存数据和所有认证状态。

**当前情况：** 已支持用户名、密码登录、记住登录状态、会话恢复和退出，但浏览器端仍保存了可还原的认证参数。

### 2. 真实网关 API 对接与权限控制

- [ ] 明确定义并实现业务网关认证、设备、分组、事件、用户和远程会话 API。
- [ ] 所有写操作在服务端执行权限校验，不依赖前端按钮隐藏。
- [ ] 为设备操作、文件上传、电源指令和远程会话记录审计日志。
- [ ] 统一处理网关请求超时、断线、重连和重复提交。
- [ ] 补充生产环境配置说明，移除代码中的默认生产网关地址。

### 3. 核心流程测试

- [ ] 登录、退出、会话恢复和会话过期测试。
- [ ] 受保护路由与权限测试。
- [ ] 网关断线、自动重连和快照恢复测试。
- [ ] 设备筛选、详情和设备操作测试。
- [ ] 文件上传、取消、失败重试和断线恢复测试。
- [ ] 增加浏览器端端到端测试。

## 功能完成定义

每项功能标记为完成前，至少应满足：

- UI 已完成加载、空数据、错误、无权限和断线状态。
- 前端和业务网关接口均已实现。
- 服务端已执行认证、授权、输入校验和审计记录。
- 操作成功与失败均有明确反馈。
- 已覆盖核心单元测试或集成测试。
- 涉及关键用户流程时已增加端到端测试。
- 已通过 `pnpm lint`、`pnpm typecheck`、`pnpm test` 和 `pnpm build`。
- 文档和环境变量示例已经同步更新。
