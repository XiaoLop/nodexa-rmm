## 统计语义

在远程桌面工具栏展开“性能详情”，每秒更新一次，可导出最近最多 300 次采样。导出不包含画面、输入、设备 ID、地址、Cookie 或凭据；设备环境由验收者用非敏感标签另行记录。浏览器后台计时可能受限，因此用 elapsedMs 计算实际时间，不假定每两个样本恰好相隔一秒。

- 接收字节和图块是会话累计值，字节含桌面应用消息，不含 WebSocket/RTC 线协议开销。
- 待处理协议字节不包含绘制队列；两者分别显示。
- 绘制批次是一轮 requestAnimationFrame 内顺序提交的图块批次；静止桌面没有更新属正常现象，图块和批次均非远端 FPS。
- 解码耗时为解码开始到完成，入队至绘制耗时包含排队、解码、顺序等待和等待绘制。平均值为当前画面队列累计值；P95 使用最近最多 2048 个已绘制图块，不等于整段录像的精确 P95。
- 尺寸变化重建绘制队列，绘制计数归零；按屏幕尺寸和计数回退拆分统计区间，不能直接跨区间相减。
- WebRTC 显示的是协商状态及实际传输类型，不能据此证明连接为直接路径。
- 未丢弃当前画面的增量块。待处理压缩图像负载超过 8 MiB 时结束会话并提示重新连接；解码/绘制失败同样结束会话，避免留下无法恢复的增量画面。

## 对照采集步骤

1. 使用获授权的测试设备，记录 Agent 版本、操作系统、浏览器版本、屏幕尺寸/DPI、链路类型及服务端版本；同一轮保持一致。真实环境凭据按 `test/README.md` 配置，不提交采集中的业务数据。
2. 建立新会话并等待首屏完整，分别使用 WebP/58/100、WebP/58/50、JPEG/58/100、JPEG/58/50；再比较拟定流畅预设 WebP/45/50。
3. 每组先留 5 秒稳定期，再分别执行静止桌面、固定页面连续滚动、拖动同一窗口各 30 秒，每种场景重复三次。每轮重新连接，导出统计并用场景、参数、重复编号命名；不要在同一测量段改参数。
4. 以 elapsedMs 和累计 drawBatches 的差值计算每秒可见绘制批次，比较各轮中位数；查看队列走势及末尾等待 P95。需更严格比较整个测量段的 P95 时，固定相同图块采样窗口，或增加独立详细性能采集，不能平均多个 P95。
5. 对流畅预设连续操作 5 分钟，观察队列是否持续增长，并确认拖动、键盘、滚轮、黑边、全屏、仅查看权限、断开重连及 WS 回退。
6. 目标 Agent 单独验证缩放参数换算与回包尺寸、坐标定位和恢复 100%。通过之前不得启用 75%/50%。
